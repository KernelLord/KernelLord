# Publish your profile: KernelLord

This repository is the public profile README for [github.com/KernelLord](https://github.com/KernelLord). GitHub renders `README.md` on the profile because the public repository name matches the username.

## Components in this build

| Component | Role |
|---|---|
| [Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg) | Animated profile principles under the hero |
| [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats) | Pickysteve pin, account stats, and language card |
| [Activity Graph](https://github.com/ashutosh00710/github-readme-activity-graph) | Recent activity signal with custom colors |
| [Profile Trophy](https://github.com/ryo-ma/github-profile-trophy) | Dynamic achievement row |
| [Skill Icons](https://github.com/tandpfun/skill-icons) | Technology stack |
| [Platane Snake](https://github.com/Platane/snk) | Contribution graph animation |
| [GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib) | Three dimensional contribution calendar |
| [Capsule Render](https://github.com/kyechan99/capsule-render) | Footer treatment |

The profile intentionally features only the public [Pickysteve](https://github.com/KernelLord/pickysteve) build.

## GitHub setup

1. Keep this repository public and keep its name exactly `KernelLord`.
2. In **Settings → Actions → General**, set workflow permissions to **Read and write**.
3. Run **GitHub-Profile-3D-Contrib** and **Generate Snake** once from the Actions tab to seed their generated visuals.
4. In **Settings → Profile**, enable **Include private contributions on my profile** if you want GitHub’s aggregate contribution graph to include private activity without exposing private repositories.

## Visual system

The profile uses near-black `#0D0D0D`, gold `#F5B301` and `#FFC83D`, purple `#A855F7` and `#8B5CF6`, crimson `#B11226`, and terminal green `#54E59A`.

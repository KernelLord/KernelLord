# Publish your profile — KernelLord

This repository is the public profile README for [github.com/KernelLord](https://github.com/KernelLord). Because the repository is public and named exactly `KernelLord`, GitHub renders `README.md` at the top of the profile.

## What is in this build

| File | Purpose |
|---|---|
| `README.md` | The public profile command center and Pickysteve showcase |
| `assets/banner.svg` | Custom KernelLord hero artwork with reduced-motion support |
| `assets/console.svg` | Animated terminal-console visual for the active build |
| `assets/hud.svg` | Animated systems monitor visual |
| `assets/radar.svg` | Skills radar |
| `.github/workflows/snake.yml` | Contribution graph snake on the `output` branch |
| `.github/workflows/profile-3d.yml` | Isometric contribution skyline |

## GitHub setup

1. Keep the repository **public** and keep its name exactly `KernelLord`.
2. In **Settings → Actions → General**, set workflow permissions to **Read and write**.
3. Run **GitHub-Profile-3D-Contrib** and **Generate Snake** once from the Actions tab to seed their generated visuals.
4. In **Settings → Profile**, enable **Include private contributions on my profile** if you want GitHub’s aggregate contribution graph to include private activity without exposing private repositories.

The profile intentionally highlights only the public [Pickysteve](https://github.com/KernelLord/pickysteve) build. Keep private project names and links out of public copy, SVG labels, badges, and documentation.
